# personal

## Preview the website on your computer

1. On GitHub, select **Code → Download ZIP**.
2. Unzip the downloaded folder.
3. Open **index.html** in Safari, Chrome, or Firefox. Keep the other files in the same folder.
4. Scroll to travel along the tree-lined path and reveal the portfolio.

These files do not require installation or a build. Uploading them does not enable GitHub Pages or deploy the site.
